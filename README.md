# Industrial-Engineer-Construction-Safety-CBT

건설안전산업기사 필기 CBT. React·TypeScript·Vite로 만든 비공식 학습 도구이며 서버·로그인·유료 API 없이 브라우저에서 실행한다.

전기기능사 CBT의 화면·기능을 표준으로 재사용했다. 스킬은 최신 main `76b990b8720adfa85c22a0a8f699b17094aa357b`의 v1.4.0, 앱은 고정 기준 `b9a682ccff1b460334b78d5bfad9375b7ec4fbb6`을 사용했다. 원본 앱 MIT 고지를 LICENSE에 보존했다. 원본 전기 문제는 포함하지 않는다. 기존 AGENTS.md는 없었으며 새 연결 문서와 `.agents/skills/cbt-site-standard/` 전체를 추가했다.

## 시험 설정과 확인 한계

**최신 공식 규칙·출제기준 대조는 미완료다.** Q-Net 확인 요청이 환경 프록시의 `CONNECT 403 Forbidden`으로 차단되었고, 사용자 지시에 따라 우회하지 않았다. 아래는 구현한 학습용 설정으로 공식 검증 완료 규칙이 아니다. 확인 상태·실제 오류는 [시험 규칙 기록](docs/exam-rules.md)에 있다.

- 학습 과목: 산업재해 예방 및 안전보건교육 / 인간공학 및 위험성 평가·관리 / 건설재료 및 시공 / 건설공사 안전관리.
- 각 20문항, 총 80문항, 객관식 4지선다, 120분.
- 과목별 100점, 전체는 네 과목 평균. 평균 60점 이상이며 각 과목 40점 이상. 미응답은 오답이다.
- 전기기능사 규칙을 기본값으로 복사하지 않았다. 모든 설정은 `src/qualification.json`에서 관리한다.

## 실제 문제은행

| 학습 과목 | 개념형 | 숫자 조건 변형 | 합계 |
| --- | ---: | ---: | ---: |
| 산업재해 예방 및 안전보건교육 | 20 | 240 | 260 |
| 인간공학 및 위험성 평가·관리 | 20 | 240 | 260 |
| 건설재료 및 시공 | 20 | 200 | 220 |
| 건설공사 안전관리 | 20 | 240 | 260 |
| 합계 | 80 | 920 | 1,000 |

중복 제거 후 기본 JSON 등록·내부 검수 완료 1,000, 검증 대기 0, 수량 부족 0. 기출 0·복원 0·자체 제작 1,000이다. 숫자 변형은 23개 유형 × 40개 조건이다. 개념 원고 80개와 계산 23유형으로 구성했으므로 1,000개 독립 개념을 뜻하지 않는다. 사용자 개인 등록분은 이 수량에 포함하지 않는다.

AI의 일반 지식과 명시된 계산 가정으로 자체 작성했다. 기출 연도·회차는 모두 null이다. 검수는 내부 문장·보기 검토, 구조·중복 전수 검사, 별도 언어의 920개 독립 재계산이다. 외부 전문가 검수·공식 출제기준 대조는 미완료이며 계산형 비중과 학습 범위에 한계가 있다. 전체 공식 시험 대비 표준을 완전히 충족했다고 주장하지 않는다. 상세 근거·유형·이용 조건은 [문항 검수 기록](docs/question-review.md)에 있다. 데이터는 CC BY 4.0이며 저장소 링크·기여자·변경 여부를 표시해야 한다. 외부 기출 재배포 권한을 뜻하지 않는다.

## 기능

- 두 모드: 실전 모의시험, 과목 선택 랜덤 문제풀이. 학습 기준·연도 버전 선택 메뉴는 없다.
- 시험: 고유 ID 무작위 추출, 숫자 family 우선 분산, 한 문제씩/번호 패널/답안 수정, 절대 종료 시각, 새로고침 복원, 만료 자동 제출, 별도 제출 확인, 평균·과락 판정과 과목별 결과.
- 실전은 답안 선택 후, 랜덤은 즉시 채점 후 **Space로 다음 문제**. 본문 포커스, 미응답·길게 누르기·수정키·입력/선택 컨트롤·메뉴·대화상자 보호. 마지막 시험 문제에서 자동 제출하지 않는다.
- 결과: 전체 보기·정답·해설·출처·이용 조건, 오답 필터, 해당 시험 오답 재학습.
- 복습: 오답노트·북마크·연속 정답·정답률·취약 과목·최근 모의시험. 재학습 정답 시 오답 해제.
- 문제은행: JSON/CSV 양식, 검색·상태 필터·페이지, ID/정규화 본문+정렬 보기 중복 제거, 원자적 가져오기, 검증 대기, 근거를 남긴 사용자 로컬 승인, 내보내기. 공용 은행에 자동 게시하지 않는다.
- 기록: 자격증별 localStorage namespace. 최근 응답 5,000개·시험 30회. 화면 통계는 보관된 기록 기준이며 평생 누적값이 아니다. 기기·브라우저·origin이 다르면 기록이 분리되고 시크릿/iframe 저장 제한도 적용된다.
- JSON 백업과 확인 후 초기화. **백업 복원 UI는 없다.** 초기화는 기본 은행을 지우지 않는다. 손상 원본은 자동 덮어쓰지 않고, 저장 실패는 경고한다.
- 작은 높이·가로·글자 확대에서 독립 스크롤 가능한 모바일 메뉴. 비공식 표시는 푸터/사이드바, 상세는 문제은행 출처 패널에 둔다. 상단 상시 안내 배너는 없고 실제 저장 오류 경고는 유지한다.

## 실행과 검증

Node는 `.node-version`의 24.19.0, 지원 최소는 22.12.0이다.

```bash
npm ci --cache /tmp/construction-safety-npm-cache --no-audit --no-fund
npm run dev
npm test
python3 scripts/generate_bank.py --check
npm run build
```

브라우저 검증:

```bash
# 이 클라우드 이미지에 설치된 Chromium 이용
PLAYWRIGHT_CHROMIUM_EXECUTABLE_PATH=/usr/bin/chromium npm run test:e2e
# CI에서는 npx playwright install --with-deps chromium 후 npm run test:e2e
```

준비된 의존성과 생성 파일은 재사용할 수 있으나 서버 프로세스는 새 작업에서 다시 시작해야 한다. 기존 체크아웃을 사용하며 사용자 요청 없이 worktree를 만들지 않는다. 로컬 preview는 `npm run preview -- --port 4173 --strictPort`이고 base 경로는 `/Industrial-Engineer-Construction-Safety-CBT/`다.

실제 검증 결과와 기기 범위는 [검증 보고서](docs/validation.md)를 참조한다. 실제 모바일 기기·Safari 검사는 수행하지 않았다. 빌드는 기본 JSON 포함 번들에 대한 500kB 경고가 있으나 압축 전 약 1.83MB, gzip 약 159kB이며 빌드 실패는 아니다.

## GitHub 반영과 배포

main push → 단위/빌드/PC·모바일 검증 → Pages 자동 배포 workflow를 준비했다. PR에서는 검증만 한다. 그러나 배포 사전 확인의 **첫 GitHub API 호출이 Forbidden**으로 거부되어 사용자 지시대로 즉시 배포를 중단했다. main push·Actions 실행·재실행·대체 배포·공개 화면 확인은 하지 않았다. 코드 보존 브랜치는 `feat/construction-safety-cbt`이며 이번 작업 CI·Pages 결과는 미실행이다. 기존 Pages 설정·게시 상태는 확인하지 못했다.

현재 사용자에게 필요한 최소 확인은 저장소 **Settings → Pages**를 열어 Source가 **GitHub Actions**인지 확인하는 것이다. 이후 사용자가 직접 마무리하며 에이전트는 새로운 명시적 요청 없이는 배포를 재시도하지 않는다. 오류와 중단 근거는 [배포 기록](docs/deployment.md)에 있다.
