# 시험 규칙 확인 상태

2026-10-27 현재 **공식 원문 확인 미완료**. 다음 표는 앱에 구현한 학습용 설정이며 공식 검증 완료 규칙이 아니다.

| 항목 | 학습 설정 |
| --- | --- |
| 자격증 | 건설안전산업기사 필기 |
| 과목 | 산업재해 예방 및 안전보건교육 / 인간공학 및 위험성 평가·관리 / 건설재료 및 시공 / 건설공사 안전관리 |
| 형식 | 객관식 4지선다, 각 20개·총 80개 |
| 시간 | 120분 |
| 배점 | 각 과목 20개 동일 배점(과목별 5점), 전체 평균은 총 정답/80×100 |
| 합격 | 전체 평균 60점 이상 **그리고** 모든 과목 40점 이상 |
| 미응답 | 오답으로 처리 |
| 경계 | 48/80은 평균 60점. 단 한 과목 7/20이면 평균이 높아도 불합격. 과목 8/20은 과락 경계 통과 |

이는 2026 개편 체계로 구성한 잠정 학습 설정이다. 전기기능사의 3과목·60문항·60분·과락 없음 규칙은 복사하지 않았다. 설정은 `src/qualification.json` 한 곳에서 관리한다.

## 실제 조사와 오류

Q-Net 종목별 상세정보의 후보 주소 `https://www.q-net.or.kr/crf005.do?id=crf00503&jmCd=2390`에 HEAD 요청했으나 실행 환경 프록시에서 `HTTP/1.1 403 Forbidden`, `curl: (56) CONNECT tunnel failed, response 403`이 반환되었다. 본문에 도달하지 못했으므로 **종목 코드·과목·개편 적용일·시험시간·합격 규칙의 공식 확인 근거로 이 URL을 인용하지 않는다.**

사용자가 네트워크 차단 회피 불가를 명시하여 추가 우회 조회는 하지 않았다. 국가법령정보센터·안전보건공단의 본문 및 최신 수치 규정도 열람하지 못했다. 공식 시험 일정·응시 자격·필기 면제·실기 규칙은 앱 범위에 포함하지 않는다. 위 표를 확인 완료 자료로 사용하지 말고 응시 전 Q-Net의 해당 종목 최신 안내와 공고를 확인해야 한다.

앱에는 학습 기준 선택 메뉴나 상단 상시 면책 배너를 만들지 않는다. 비공식 표시는 사이드바/푸터에, 검증 한계는 문제은행 관리와 이 문서에 제공한다. 저장 실패와 손상 경고는 별도로 유지한다.
