## 발견·수정 사항과 한계

초기 npm 기본 캐시 경로는 쓰기 불가로 설치가 실패했다. 잠금파일·패키지 무결성·TLS 검사를 유지한 채 쓰기 가능한 `/tmp` 캐시를 지정해 해결했다. 테스트에서 교육 이수 인원이 대상자보다 커지는 생성 조건을 발견해 수정·재검증했다. 상단 배너 회귀 검사에 맞춰 통계 범위 설명을 일반 본문으로, 문제은행 한계 설명을 상세 패널로 정리했다. 최종 브라우저 실행은 실패 0이다.

Vite는 기본 JSON 포함 번들 크기에 대해 500kB 경고를 출력했다. 최종 JS 약 1.831MB / gzip 159.56kB이며 빌드 성공과 구별해 기록한다. 데이터 정확성은 내부 검수 범위이며 자동 계산 통과가 외부 전문가 검수나 공식 출제기준 검증을 대신하지 않는다.
