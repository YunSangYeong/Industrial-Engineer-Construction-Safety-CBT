# 문제은행 출처와 검수 기록

작성일: 2026-10-27 (한국 시간). 기본 은행은 `src/data/questions.json`이며 생성 원고는 `scripts/concepts.txt`, `scripts/generate_bank.py`다.

## 출처·이용 조건

- 1,000개 모두 이번 작업에서 AI가 자체 작성한 학습문항이다. 기출 원문 0, 복원 0. 민간 문제 사이트와 전기기능사 문제는 복제하지 않았다.
- 연도·회차는 모두 `null`이다. 발행 시점이나 Git 커밋을 기출 연도로 쓰지 않는다.
- 개념 문항은 AI의 일반적인 건설 안전·재료·인간공학 지식에 기반한다. 열람하지 않은 교재·공식 출제기준을 정답 근거로 인용하지 않는다.
- 계산 문항은 문제에 명시한 일반 수학·역학·확률·통계 정의에 따른다. 법정 기준값, 안전장비의 허용값, 실제 구조 설계의 적합성을 묻지 않는다.
- `sourceUrl`은 이 작성·검수 기록이다. 저장소 URL을 외부 정답 검증 자료로 간주하지 않는다.
- 자체 데이터는 CC BY 4.0이다. 표시: **건설안전산업기사 CBT 기여자**, 이 저장소 링크와 변경 여부를 명시한다. 제3자 기출의 이용 권한을 부여하는 라이선스가 아니다.
- 공공 웹페이지 열람 가능 여부와 재배포 허용 여부는 다르다. 이번 작업에서는 재배포 조건까지 확인된 기출을 확보하지 못했다.

## 실제 구성

| 학습 과목(공식 원문 대조 대기) | 개념 | 계산 변형 | 합계 |
| --- | ---: | ---: | ---: |
| 산업재해 예방 및 안전보건교육 | 20 | 240 (6유형) | 260 |
| 인간공학 및 위험성 평가·관리 | 20 | 240 (6유형) | 260 |
| 건설재료 및 시공 | 20 | 200 (5유형) | 220 |
| 건설공사 안전관리 | 20 | 240 (6유형) | 260 |
| 합계 | 80 | 920 (23유형 × 40조건) | 1,000 |

독립 개념 원고 80개와 계산 유형 23개, 총 103개 원고/유형에 기반한 1,000개 조건별 문항이다. 1,000개 독립 개념이나 1,000개 기출을 뜻하지 않는다. 계산형 비중이 매우 높고 개념·법규의 범위가 제한적이므로 공식 시험의 범위·난이도·출제 비율을 대표한다고 볼 수 없다.

## 내부 검수 범위

1. 개념 80개: 질문의 조건, 정답 보기, 세 오답과 해설의 일치·모호함을 내부 검토했다. 감전 구조·밀폐공간 구조·보호구 등에서는 현장 안전과 추가 피해 방지를 우선하도록 문장을 검토했다. 유사 분야 주제는 반복 학습 항목이며, 동일한 질문을 어순만 바꾸어 채우지 않았다.
2. 계산 23유형: 식과 단위·가정·입력 범위·해설을 내부 검토했다. 유형별 40조건을 고정 순서/고정 ID로 생성한다. 무작위 생성 시드가 없으며 모든 조건은 식과 인덱스로 결정된다.
3. 독립 수치 검사: Python Decimal 생성과 별도 TypeScript 계산식으로 920개를 재계산한다. 반올림, 정답 위치, 단위, 수치 동치 보기, 확률 범위, 이수자≤대상자 및 조건 조합 고유성을 검사한다. 검사 중 발견된 이수 인원 초과 생성 조건은 수정하고 재검증했다.
4. 중복: ID와 NFKC·공백 정규화한 본문+정렬 보기 기준으로 전수 확인한다. 같은 숫자 유형의 의미상 반복은 제거 대상 개념 중복으로 숨기지 않고 `family`로 공개한다. 개념 원고 80개와 23식 간 주제를 읽어 점검했으나 외부 의미 유사도 판정이나 전문가의 중복 검수는 하지 않았다.
5. 재생성: `python3 scripts/generate_bank.py --check`로 원고와 JSON의 byte 일치를 확인한다.
6. 상태: 기본 1,000개는 위 범위의 **내부 검수 완료(reviewed)**, 검증 대기 0, 제외 문항 0, 수량 부족 0이다. 사용자 로컬 등록분은 이 집계에서 제외한다.

**외부 전문가 검수와 공식 출제기준 대조는 미완료**다. 자동 계산 검사만으로 개념·해설 전체의 공식 정확성이 입증됐다는 뜻은 아니다. 이 한계 때문에 전체 공식 시험 대비 표준을 충족했다고 주장하지 않는다.

## 출제 정책

모의시험은 학습 설정의 4과목에서 20개씩, 총 80개를 뽑는다. 과목별로 개념 ID와 숫자 `family`에 먼저 한 슬롯씩 주어 같은 계산 변형 유형이 한 시험에 여러 번 나타나는 것을 방지한다. 가져온 은행에 독립 그룹이 부족하면 남은 고유 ID로 보충한다. ID 중복은 허용하지 않는다. 랜덤은 선택 범위 내 ID를 모두 순회하기 전 같은 ID를 다시 뽑지 않으며, 모든 문항의 확률이 같다.
